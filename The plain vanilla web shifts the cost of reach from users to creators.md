# The plain vanilla web shifts the cost of reach from users to creators

Modern web tools and frameworks pass the cost of access to users, typically in
the form of updated hardware and bigger data plans. Websites built in plain
vanilla ask a creator to pay the cost of manual implementation and optimization
so that users can reach the site without the latest hardware or unlimited data
plans.
