# Desktop made for one — the idea

The idea behind the proof-of-concept: a desktop environment built for a single, known user rather than a general audience — where "audience of one" is a design freedom, not a limitation.

> Seed — the thought is not yet written. What does building for one user let you drop,
> assume, or hard-code that a general-purpose desktop can't?
