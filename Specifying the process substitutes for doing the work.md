# Specifying the process substitutes for doing the work

Refining the system is adjacent to the work and always available, and unlike the work
it terminates: a rule can be finished in an afternoon, where a claim cannot be forced
into existence on schedule. It also produces artifacts — conventions, folders,
templates, a ladder of statuses — that any reviewer including yourself will read as
infrastructure rather than as avoidance, so nothing in the ordinary course of review
catches it. The substitution then compounds, because each addition to the apparatus
raises the standard a note must meet before it is worth writing at all.

The order of events is what identifies it: the specification arrives after production
has already stopped, as the thing you do instead, rather than before it as preparation.
