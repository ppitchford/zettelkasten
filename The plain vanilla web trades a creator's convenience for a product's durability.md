# The plain vanilla web trades a creator's convenience for a product's durability

Modern web frameworks and tools allow creators to build websites fast, but
also come with more dependencies which can lead to rot. A plain vanilla website
contains far fewer dependencies and has fewer moving parts, which result in
easier long-term maintainability.
