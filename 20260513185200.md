# Managing ornatus

Wayland-native solar-gradient wallpaper and theme daemon. Source at
`~/projects/ornatus/`, repository at `github.com/ppitchford/ornatus`. Replaces
the previous swww + bash `theme-switch` stack on MangoWM.

## Rebuild and reinstall

After changing the source:

```sh
cd ~/projects/ornatus
cargo build --release
install -Dm755 target/release/ornatus ~/.local/bin/ornatus
```

The release build takes 30–60 s (LTO is enabled). If a daemon is already
running, restart it:

```sh
pkill ornatus
ornatus &
disown
```

## Filesystem layout

| Purpose          | Path                                              |
|------------------|---------------------------------------------------|
| Binary           | `~/.local/bin/ornatus`                            |
| Source           | `~/projects/ornatus/`                             |
| Config           | `~/.config/ornatus/config.toml`                   |
| Location cache   | `~/.cache/ornatus/location.json`                  |
| Frame images     | `~/Pictures/wallpapers/solar-gradients/NN.jpg`    |
| Theme bundles    | `~/.config/theme/{dark,light}/`                   |
| Current marker   | `~/.config/theme/current`                         |

## Configuration

Defaults are written to `~/.config/ornatus/config.toml` on first run.
Editable keys:

```toml
wallpaper_dir         = "/home/philipp/Pictures/wallpapers/solar-gradients"
theme_dir             = "/home/philipp/.config/theme"
refresh_interval_secs = 60

[location]
source = "auto"           # or "fixed"

# For fixed mode:
# source = "fixed"
# lat    = 32.8595
# lon    = -117.2124
```

Changes take effect on next launch.

## Running and stopping

Autostart: `exec-once=~/.local/bin/ornatus` in `~/.config/mango/config.conf`.

Manual control:

```sh
ornatus &           # foreground a backgrounded process
pkill ornatus       # stop
```

## Debugging

Verbose logs:

```sh
pkill ornatus
RUST_LOG=ornatus=debug ornatus
```

Logs go to stderr. Under autostart, stderr inherits from mango — typically
discarded unless mango itself is redirecting. For long-term log capture
during autostart, redirect explicitly in the exec-once line.

To verify the refresh loop without waiting:

1. Set `refresh_interval_secs = 5` in config.
2. Restart ornatus.
3. Run with `RUST_LOG=ornatus=debug` and watch for `refreshed` lines.
4. Restore to 60 afterwards.

## Frame and theme requirements

Frame images in `wallpaper_dir` must be named `00.jpg` through `15.jpg`,
matching macOS Solar Gradients index order. Each is resized at load time
to each output's native pixel dimensions.

Theme bundles in `theme_dir/{dark,light}/` must contain:

- `kitty.conf` — terminal colours
- `fuzzel.ini` — launcher
- `mako.conf` — notifications
- `mango.conf` — compositor border colours

ornatus swaps symlinks into the active bundle and signals each app to
reload (`pkill -SIGUSR1 kitty`, `makoctl reload`, `mmsg -d reload_config`).
